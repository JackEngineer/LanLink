  1. 01

    两端安装，接入同一局域网

    在 Mac 和 Windows 上安装对应预览包。连接受信任的 Wi-Fi 或有线网络，再打开 LANLink。

    从设备列表发起配对。两端安全码一致后，在两台电脑上分别确认。

    发送消息，或传一份文件

    选择已配对设备即可聊天。发送文件时，对方接受后开始传输。

04 / GOOD TO KNOW

在开始之前。

连接很近的设备，
也把使用边界说清楚。

需要注册账号或连接互联网吗？+

不需要注册账号。安装包需要先从 GitHub 下载；安装完成后，消息和文件在局域网内传送，日常使用无需公网。首次从源码构建需要联网获取依赖。

Mac 和 Windows 可以互传吗？+

可以。Apple Silicon Mac 与 Windows x64 已完成双向消息、文件传输和断点恢复等实机验收。Intel Mac 提供预览包，但尚未实机验证。具体测试范围见验收记录。

为什么发现不了另一台设备？+

先确认两端 LANLink 都在运行，设备处于同一个局域网，防火墙允许受信任的专用网络访问。访客 Wi-Fi 或路由器的客户端隔离可能阻止设备互访。更多步骤见连接排查指南。

文件大小有限制吗？中断后怎么办？+

默认单文件上限为 2 GiB。文件需要接收端单独接受，断线后保留已确认进度，重新连接后继续传输。取消或拒绝的传输不会自动恢复。

文件和聊天记录存在哪里？+

身份、消息历史和接收文件保存在本机，默认卸载流程会保留这些数据。具体目录与卸载方法见安装指南。

这是正式版本吗？如何反馈问题？+

目前是开发预览，不是 v0.2.0 正式完成版。欢迎在 GitHub Issues 提交问题，说明操作系统、版本与复现步骤。请勿公开身份密钥、私人聊天或文件内容。
