# 手机扫码文字互传

手机使用浏览器扫码，电脑按现有流程确认（或按已记住的浏览器规则重连）。文字只能在本次扫码的手机和电脑之间收发，不进入电脑对电脑的聊天记录，也不能转发给第三台设备。文件互传仍使用原有入口。

手机与电脑须在同一个可信 Wi-Fi。手机会话使用局域网 HTTP，文字和文件均未加密，不用于传输敏感内容。

文字每条最多 2048 个 UTF-8 字节，每个会话最多 40 条、每方向相邻成功发送至少间隔 750 毫秒。同方向内，相同编号、相同正文的重试不会重复写入；刷新不是跨会话的投递承诺。文字只放在 Agent 的会话内存，不落盘，不带入下一次扫码。保持同一活跃会话及浏览器凭证时，刷新会重新读取文字。连接断开导致桌面轮询失败时暂不显示旧文字，恢复后重新获取；过期或撤销后不能读取或再发送。界面隐藏不等同于立即擦除浏览器进程内存或用户截图。

开发验收覆盖进程内路由鉴权与请求上限、现有文件回归、延迟旧响应不会恢复已结束界面、短暂轮询失败后恢复和页面重载。尚未做手机/电脑真机、局域网或屏幕操作验收。
